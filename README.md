# いろとゆび

公開先: https://ngmt4amtk-web.github.io/iro-to-yubi/

バイオリンのラ弦（赤）とミ弦（緑）の0〜3を見て弾くアプリ。

## 今回の仕様

- 赤：ラ・シ・ド♯・レ。緑：ミ・ファ♯・ソ♯・ラ。基準A=440Hz。
- ふよみの既存3キャラを事前選択。画像は変更せず再利用。
- 1フレーズ4音。1・3・5フレーズを選ぶ。
- 各音への切り替えでキャラが登場。正解でジャンプと紙吹雪。
- 全フレーズ終了時に大きなキャラと紙吹雪。全音正解なら「ぜんぶ できた！」、それ以外は「さいごまで できた！」。
- タイムバーと残り秒表示は非表示。
- 正解後850msの演出で次へ。無音では待機。間違い検出時にお手本を1回鳴らし、その検出から4秒後に次へ。待機中の弾き直しが正解なら通常の正解演出で進む。
- ピッチ判定は半音以内とオクターブ違いを許容。許容範囲を外れた音が480ms続くとお手本。
- お手本の再生後までマイク判定を止め、自分の音を正解に数えない。
- 休憩・画面非表示・終了でマイク停止。再開時は現在の音から判定し直す。
- 外部依存なし。音声はブラウザ内で処理し、保存・送信しない。

## マイクの拾い率 2026-10-10

「先生の設定」に、お手本の音量と同じ形式の3段階スライダーを追加。保存値がない場合の既定値は「超高め」。選択は `localStorage` の `iro-to-yubi:mic-pickup` に保存する。不明な保存値や保存領域の読み取り失敗時も「超高め」で始め、書き込みに失敗してもその場での設定変更は適用する。

判定値は `dist/engine.mjs` の `MIC_PICKUP_LEVELS` に集約し、音程検出と正誤判定の両方で同じ段階を使う。「ふつう」は従来の判定値を維持している。

| 段階 | 音量下限（RMS） | 周期の確からしさ下限 | 許容する音程差 | 正解の保持時間 | お手本までの保持時間 |
| --- | --- | --- | --- | --- | --- |
| ふつう | 0.002 | 0.65 | ±100セント | 180ms | 480ms |
| 高め | 0.001 | 0.55 | ±125セント | 120ms | 480ms |
| 超高め（既定） | 0.0005 | 0.45 | ±150セント | 60ms | 480ms |

RMSは音の大きさを表す値、周期の確からしさは音程を推定する根拠の強さで、いずれも下限を低くするほど拾いやすくなる。100セントは半音。音程差の境界には従来どおり0.01セントの丸め誤差の余裕を設け、オクターブ違いも受け入れる。保持時間は判定に使う音が続いた時間で、各音の開始直後200msの待機や、観測が途切れた場合の扱いは維持する。

誤判定から4秒後の進行、正解後850msの演出、お手本の音・音量初期値85%・再生中のマイク判定停止、既存の設定と表示文言は維持。マイク音の録音・保存・送信は追加していない。
